# COLOR FACTORY

A portrait, hyper-casual color sorting game for mobile browsers. Sort it. Match it. Keep it moving.

GoatCounter records cookie-less game events and return visits. Analytics is optional; the game continues to work offline or when the analytics script cannot load.

## Rules

Tap the lane button matching the active ball before it reaches the diverter. Correct sorts add one point and increase the combo; wrong sorts and missed balls cost a life. Three mistakes end the run. Lanes redraw as the color pool expands. Difficulty increases in score bands, and combos announce GOOD, GREAT, PERFECT, then FANTASTIC.

## Run locally

- npm run dev starts the Vite development server.
- npm run build type-checks and builds the production site.
- npm run build:preview builds the review version into dist-preview/ with assets rooted at /color-factory/preview/.
- npm test runs the standalone TypeScript rules tests with Node 24.

## Deploy

Build with npm run build and publish the contents of dist/ to the color-factory GitHub Pages project path. For a review deploy, run npm run build:preview and publish dist-preview/ under /color-factory/preview/. The preview service worker uses its own cache prefix and relative registration scope, so it can coexist with the live version. The generated service worker precaches the build so the game works offline after the first successful visit. The source artwork for app icons and iPhone launch screens is generated by python3 tools/make_icons.py (requires Pillow).
